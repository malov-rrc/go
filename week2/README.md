## P0-A — 5 закрепляющих программ, 1,5 часа

Каждая — отдельная папка (`task11-...` … `task15-...`), свой `main.go`, запуск через `go run`.

**11. Вариативные функции**
`func SumAll(nums ...int) int`. В `main` вызвать и напечатать:
`SumAll(1, 2, 3) = 6`, `SumAll() = 0`, `SumAll(5) = 5`.

**12. Замыкания**
`func NewCounter() func() int` — при каждом вызове увеличивает и возвращает внутренний счётчик, старт с 1.
В `main`: `counter1` → вызвать 3 раза → напечатать `1`, `2`, `3` на отдельных строках. Затем `counter2` → вызвать 1 раз → напечатать `1` (доказывает независимость счётчиков).

**13. Сортировка через `sort.Slice`**
`type Person struct { Name string; Age int }`. Хардкод: `{"Anna",34}, {"Boris",22}, {"Vera",45}, {"Gleb",22}`.
Сортировать по `Age` **по убыванию**; при равном `Age` — по `Name` **по возрастанию** (детерминированность).
Напечатать список до и после сортировки, построчно: `Имя (Возраст)`.

**14. Pointer receiver**
`type Counter struct { count int }`, метод `func (c *Counter) Increment()`.
В `main`: `Counter{}` → `Increment()` 3 раза → напечатать `count` (должно быть `3`).
В коде — комментарий на 1–2 предложения: почему обязателен именно pointer receiver, а не value receiver.

**15. Рекурсия**
`func Factorial(n int) (int, error)`. `n < 0` → ошибка (не паника). `n == 0` → `1, nil`.
Table-driven тест: `0→1`, `1→1`, `5→120`, `-1→error`.

## P0-B — каталог книг, 3 часа

CLI-программа, вход — текстовый файл, формат `Title,Author,Year,Status` (без пробелов вокруг запятых, без CSV-экранирования — `strings.Split(line, ",")`, ровно 4 поля). `Status` ∈ `{read, reading, planned}`.

Пример входа:
```
1984,George Orwell,1949,read
Dune,Frank Herbert,1965,reading
Neuromancer,William Gibson,1984,planned
```

Запуск: `go run main.go books.txt`

**Фиксированный порядок вывода (всегда, включая случай без ошибок):**
```
Total: N
By status: read=X, reading=Y, planned=Z, unknown=W
Invalid lines: K
Sorted by year:
YEAR - Title (Author)
...
```

Правила по каждой строке вывода:

- **`Total`** — количество валидных строк. Пустые строки (после `strings.TrimSpace`) не считаются и не попадают ни в Total, ни в Invalid.
- **`By status`** — порядок статусов в строке жёсткий: `read, reading, planned, unknown` — именно в этом порядке, не зависит от порядка в файле и не через обход map. Каждый статус в строку добавляется, только если count > 0. Сравнение статуса — **точное, регистрозависимое**, без нормализации; не совпало с одним из трёх — `unknown`.
- **`Invalid lines: K`** — строка выводится, **только если K > 0**, идёт сразу после `By status`, перед `Sorted by year`. Невалидна строка, если: не ровно 4 поля через запятую, ИЛИ `Year` не парсится как число (`strconv.Atoi`) — диапазон года не проверяется, важен только факт успешного парсинга.
- **`Sorted by year`** — сортировка по `Year` по возрастанию; при равном `Year` — по `Title` по возрастанию (детерминированность, как в задаче 13).

**Структура кода:**
- `type Book struct { Title, Author string; Year int; Status string }`
- отдельная функция `parseLine(line string) (Book, error)`
- table-driven тесты на минимум 3 кейса: валидная строка, строка с неверным числом полей, строка с нечисловым годом

**Обязательно перед сдачей:** руками прогнать файл с невалидной строкой (не через мысленную проверку, а реальным запуском) и глазами убедиться, что `Invalid lines` меняется — на прошлой неделе именно такая ветка молчала из-за путаницы в том, в какое поле пишется значение.

Файл не найден → понятная ошибка в stderr + `os.Exit(1)`, без паники.

- [ ] `go vet ./...` — пусто

- [ ] вывод на примере совпадает с образцом, включая порядок блоков и порядок статусов

**16. Кастомные ошибки (~30 мин).** `ValidationError{Field, Msg}` с `Error() string` → `"<Field>: <Msg>"`. `ValidateAge(age int) error`: `age < 0` → `&ValidationError{"age","must be non-negative"}`, иначе `nil`. В `main`: вызов с `-5` и `30`; для ошибки — через `errors.As` извлечь `*ValidationError`, напечатать `.Field`; для `30` — напечатать `"ok"`.

**18. Композиция (~30 мин).** `Animal{Name}` с `Speak() string` → `"<Name> makes a sound"`. `Dog{Animal; Breed string}` — embedding без имени поля. В `main`: `dog.Speak()` (метод "бесплатно" через embedding) + свой метод `Dog.Bark()`.

**19. Пакет `flag` (~30 мин).** Таблица умножения через `flag.Int("n", 10, ...)` вместо ручного `os.Args`. `-n=5` → 5×5, без флага → 10×10 (дефолт из `flag.Int`, без ручных проверок длины).
